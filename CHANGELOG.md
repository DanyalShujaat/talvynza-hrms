# Changelog

## v0.2.0 - Connected HR Workflows

- Connect employee profiles with branch and department placement, attendance, payroll, and onboarding records.
- Guide administrators through organization setup before employee creation, bulk import, or hiring.
- Manage branch premises on a map and apply web, mobile, or biometric access by branch, department, or employee selection.
- Open requests at the matching source record. Link payroll and exit workflows to the employee records they use.
- Preserve navigation filters, improve mobile layouts, and refresh the Tali workspace assistant.
- Document system architecture and the main HR workflows with diagrams.
